## Process gap worth flagging
`kolably_ui`'s CI (`.github/workflows/ci.yml`) runs `npm run lint` and
`npm run test` only — **not** `tsc --noEmit` or `vite build`. A genuine
TypeScript compile error (referencing an undefined variable) shipped to
production because of this gap. Worth raising with the user: adding a
typecheck/build step to CI would have caught both this and would catch
similar mistakes before they reach `main`, let alone production.
